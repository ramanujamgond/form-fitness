## 11. Sets, Repetitions, and Training Terminology

The guide needs to explain gym terminology in beginner-friendly language.

| Term                 | Meaning                                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| Repetition (rep)     | One complete execution of an exercise. One push-up is one rep.                                            |
| Set                  | A group of repetitions performed before resting. Ten push-ups followed by rest is one set of 10.          |
| Working set          | A set performed with a load and effort intended to stimulate training adaptation, excluding warm-up sets. |
| Rest interval        | The time taken to recover between sets.                                                                   |
| Warm-up              | Light activity and preparatory movements before the main workout.                                         |
| Progressive overload | Gradually increasing training difficulty as the body adapts.                                              |
| Training split       | How exercises or muscle groups are distributed across the training week.                                  |
| Training volume      | The amount of work performed, commonly tracked using sets and repetitions.                                |
| Failure              | The point at which another repetition cannot be completed with proper technique.                          |
| Recovery             | The time and resources needed for the body to adapt after training.                                       |

The plan should distinguish between total repetitions and sets. For example, completing 100 push-ups could mean 10 sets of 10 or a different combination of sets, depending on the user's capacity.
